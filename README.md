# Sales Data Exploratory Analysis

## Objective
Explore sales data to find patterns and trends (time, category, region, discounts) and communicate them with clear charts that support data-driven decisions.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn (Google Colab)

## Dataset
`sales.csv`: about 3,000 orders (2023 to 2025) with Order ID, Order Date, Region, Category, Sub-Category, Quantity, Unit Price, Discount, Sales, Profit. Synthetic data with missing values and duplicate rows added on purpose to practise cleaning.

## Process
1. Load and inspect the data
2. Clean it (duplicates, missing values, data types, outliers)
3. Feature engineering (year, month, quarter, day of week, profit margin)
4. Exploratory analysis with 10 charts
5. Insights and recommendations
